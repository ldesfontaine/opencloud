# openCloud v0.4.2

Depuis la [v0.4.1](v0.4.1.md). Les numéros `#…` sont ceux des tickets Forgejo.

## L'essentiel

- **Refonte UX C1+C2** : une fenêtre modale commune, des confirmations dans l'interface (plus de boîte du navigateur) et l'assistant **Ajouter une machine** en fenêtre (#400).
- **La version s'affiche** dans Paramètres › À propos, avec un repère « agent en retard sur le serveur » (#399).
- **Stabilité des tests** (#390) : aucun effet pour l'opérateur.

| Quoi | Ce que ça apporte | Issue |
| --- | --- | --- |
| Fenêtre modale | Un seul composant de fenêtre pour les formulaires et les confirmations ; la liste reste en fond | #400 |
| Confirmations | Les gestes à confirmer s'ouvrent dans l'interface, plus dans une boîte du navigateur | #400 |
| Ajouter une machine | L'assistant s'ouvre en fenêtre sur la liste des machines | #400 |
| Garde-fous du front | Les écritures du front passent par un registre de routes ; un test vérifie la parité entre l'interface et le MCP ; code mort retiré | #400 |
| Version affichée | Paramètres › À propos montre la version et le commit du serveur ; la fiche d'une machine signale un agent « en retard sur le serveur » | #399 |
| Tests d'audit | L'attente d'audit cible le refus de l'agent pour l'ordre envoyé | #390 |

## À faire en mettant à jour

1. **Sauvegarder la base** avant de remplacer le binaire ([Mettre à jour](../installation.md#mettre-à-jour)).
2. **Le serveur seul suffit** pour voir les nouveautés d'interface.
3. **Aucune migration nouvelle** depuis la v0.4.1 : la base reste en migration `023`, et un retour au binaire v0.4.1 reste possible.
4. **Les agents n'ont rien à gagner** : leur code ne change pas (seuls un helper inutilisé de `agentwire` et un test changent). Le protocole est inchangé ; un agent v0.4.1 reste connecté. Mettez-les à jour si vous voulez que le repère de version soit à zéro.
5. **Configuration (`config.toml`) : aucun changement requis.**

## Ce qui change / casse

Aucune route retirée ni renommée, aucun champ retiré.

| Quoi | Avant | Maintenant |
| --- | --- | --- |
| `GET /api/session` | `version`, `language`, … | + `commit` (texte, vide si inconnu) ; un client qui ignore les champs inconnus n'est pas touché |
| Adresses | `/machines/nouvelle` ouvrait une page | `/machines/nouvelle` reste une adresse valide : elle ouvre la fenêtre sur la liste des machines. `/machines/jeton` ouvre de même la fenêtre du jeton d'enrôlement |
| Confirmations | Boîte du navigateur (`window.confirm`) | Fenêtre de l'interface |

## Ce que ça ne fait pas

- Le repère « agent en retard » compare des versions : il ne met pas l'agent à jour.
- La refonte UX continue : cette version n'en livre que les deux premiers lots (C1 et C2).
